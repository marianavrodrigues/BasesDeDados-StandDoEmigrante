## Sobre o projeto
O projeto tem como objetivo melhorar a gestão de uma empresa de alguer de veículos (Stand do Emigrante). Organiza informação sobre clientes, alugueres, veículos, funcionários, stands e pagamentos. 

É um projeto de conceção e implementação de uma base de dados, contém levantamento e análises de requisitos, modelação conceptual e lógica e a exploração de mecanismos SQL para consulta e gestão dos dados. 

## Tecnologias utilizadas
- MySQL - Gestão da base de dados, consultas, vistas, triggers, procedimentos e permissões.
- Python - Script de importação de dados.
- JSON e CSV - Formatos dos ficheiros utilizados para armazenamento e importação de dados.
